Vulnerabilitats que detectem

Serveis exposats que poden convertir-se en una porta d'entrada per a un atacant.

Risc ALT

Telnet (23), SMB (445, 139), RDP (3389), VNC (5900), Redis (6379) i Elasticsearch (9200) accessibles des de la xarxa.

Risc MITJÀ

FTP sense xifrar (21) i bases de dades exposades: MySQL, PostgreSQL, MSSQL i MongoDB.

Risc BAIX

HTTP sense xifrar (80, 8080). Recomanem migrar a HTTPS i revisar quins serveis han d'estar publicats.

Descarregar ZIP

Utilitza l'eina únicament en equips i xarxes on tinguis autorització.

⚙️ Instal·lació i permisos

  1. Instal·la Python 3.8 o superior. A Windows, marca «Add Python to PATH».
  2. Descomprimeix el ZIP i obre un terminal a la carpeta.
  3. Linux / macOS: chmod +x nexus.py
    ./nexus.py
  4. Windows (PowerShell o CMD): python nexus.py
  5. A Linux, si cal, instal·la Tkinter amb sudo apt install python3-tk. Per a traceroute, pots necessitar sudo apt install traceroute.
