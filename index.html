Eina gratuïta

NEXUS Network Security Scanner

La nostra eina educativa d'anàlisi de xarxes, desenvolupada amb Python i Tkinter.

Què inclou

  • Escàner de ports amb detecció de serveis
  • Banner grabbing, ping i traceroute
  • Consulta WHOIS
  • Indicadors de risc per servei
Descarrega el ZIP

Fes-la servir només en equips i xarxes on tinguis autorització.

Instal·lació

  1. Instal·la Python 3.8 o superior. A Windows, marca «Add Python to PATH».
  2. Descomprimeix el ZIP i obre un terminal a la carpeta.
  3. Linux / macOS:chmod +x nexus.py ./nexus.py
  4. Windows (PowerShell o CMD):python nexus.py
  5. A Linux, si cal: sudo apt install python3-tk traceroute
