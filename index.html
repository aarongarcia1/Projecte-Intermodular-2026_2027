```
Vulnerabilitats que detectem

Serveis exposats que solen ser la porta d'entrada d'un atacant.

Risc ALT

Telnet (23), SMB (445, 139), RDP (3389), VNC (5900), Redis (6379) i Elasticsearch (9200) accessibles des de la xarxa.

Risc MITJÀ

FTP sense xifrar (21) i bases de dades exposades: MySQL, PostgreSQL, MSSQL i MongoDB.

Risc BAIX

HTTP sense xifrar (80, 8080). Recomanem migrar a HTTPS i revisar què ha d'estar publicat.
```

```
Descarrega NEXUS

La nostra eina educativa d'anàlisi de xarxes (Python + Tkinter, només biblioteca estàndard).

📦 NEXUS Network Security Scanner

Escàner de ports amb detecció de serveis, banner grabbing, ping, traceroute, WHOIS i indicadors de risc.


Descarregar ZIP
⚠️ Utilitza-la únicament en equips i xarxes on tinguis autorització.
⚙️ Instal·lació i permisos
  1. Instal·la Python 3.8+ (a Windows marca «Add Python to PATH»). A Linux, instal·la Tkinter: sudo apt install python3-tk
  2. Descomprimeix el ZIP i obre un terminal a la carpeta.
  3. Linux / macOS , donar permisos d'execució: 
    chmod +x nexus.py
```

    ```
    python nexus.py
```
